# Published Fatiha meanings

Downloaded 2026-10-28 from QuranEnc API. Each language's translator/publisher,
version, description, source URL, exact verse text and footnotes are preserved
in fatiha_published.json and lib/data/fatiha_meanings.dart.

Terms: https://quranenc.com/en/home/api/
Republication is permitted without editing, adding to or deleting the content,
with publisher/source attribution, version and transcript information retained.
Updates should follow the source; report translation issues to QuranEnc.
Do not place inappropriate advertisements alongside the meanings.

Mapping: besmele -> verse 1; original ayet 1–5 -> verses 2–6;
both original ayet 6 and 7 -> the same complete verse 7 (user requested).
Arabic text, audio paths, stable IDs and Turkish meanings are unchanged.
No generated translations or manual paraphrases are used.
